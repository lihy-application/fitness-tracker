# 💪 小P健身打卡助手

一个清新可爱的健身打卡应用，帮助你轻松记录每次运动！

## ✨ 功能特点

- 📅 交互式打卡日历 - 可视化查看每月打卡情况
- ✍️ 运动类型记录 - 支持多种运动类型打卡
- ⏱️ 时长和卡路里追踪 - 记录每次运动详情
- 💬 运动感受备注 - 记录运动时的感受
- 🔥 连续打卡统计 - 追踪你的坚持
- 🎯 目标进度追踪 - 周目标、月度统计
- 📱 响应式设计 - 完美适配手机和桌面
- 💾 本地数据存储 - 数据保存在浏览器本地

## 🚀 部署说明

### 本地预览

直接在浏览器中打开 `index.html` 即可使用。

### 部署到 GitHub Pages

1. 克隆或 fork 这个仓库到你的 GitHub
2. 在 GitHub 仓库设置中开启 GitHub Pages
3. 选择 `main` 分支作为源
4. 访问生成的链接

## 📝 技术栈

- 纯 HTML + CSS + JavaScript
- Tailwind CSS - 样式框架
- Font Awesome - 图标库
- localStorage - 本地数据存储

## 🎨 界面预览

天青色主题，清新可爱，简洁易用！

## 💪 开始打卡

选择运动类型 → 填写运动时长和消耗卡路里 → 添加运动感受 → 完成打卡！

坚持运动，成就更好的自己！✨
